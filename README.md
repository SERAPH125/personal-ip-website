# 南吴 NANWU 内容枢纽

南吴的 AI 科技个人网站，使用 Astro 7 与 Markdown Content Collections 构建，包含作品、18 篇知识文章、Vibe Coding 与 AI 视频学习路线，以及 20 篇覆盖在线服务、桌面客户端、编辑器、插件、工作流和命令行工具的 AI 安装使用指南。

```bash
npm ci
npm run dev
```

提交前运行 `npm run check`、`npm test` 和 `node --check public/assets/hub.js`。完整的内容模型、目录与维护方法见 [开发说明](docs/README.md)，发布和回滚见 [运维说明](docs/ops.md)。
